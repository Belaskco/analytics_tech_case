# Looqbox Analytics Tech Case

Este repositório contém a solução do desafio técnico de análise de dados, estruturado como um pipeline de dados modular, seguro e performático.

---

## 📁 Estrutura do Projeto
- `queries/`: Contém as consultas SQL solicitadas, otimizadas e formatadas.
- `src/`: Contém o motor central de conexão e extração (`data_loader.py`).
- `scripts/`: Contém os scripts executáveis de cada caso de negócio.
